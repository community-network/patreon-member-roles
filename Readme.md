# Patreon member roles
This is a bot that will watch for changes in your patreon members,
and will attach the correct discord role to someone that subscribes to a tier on patreon.
To set up the bot, use "/admin tiers add" to add a connection between a tier and a discord role.

If you need further assistance with the bot. You can ask it here: https://discord.com/invite/redseccentral
